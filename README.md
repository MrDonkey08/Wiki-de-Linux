# Wiki de Linux

## Acerca de la Wiki de Linux

La [**Wiki de Linux**](https://github.com/MrDonkey08/Wiki-de-Linux/wiki) es un
recurso educativo que abarca desde temas básicos hasta avanzados. Esta wiki
busca ser un recurso que permita a cualquiera dominar la terminal, el shell
scripting y en general Linux.

Cabe destacar que el contenido de esta wiki se enfoca principalmente en dominar
Bash, la shell más popular y usada de Linux. No obstante, gran parte del
contenido puede puede ser aplicable para otras shells. Siéntete libre de
utilizar la shell de tu preferencia
